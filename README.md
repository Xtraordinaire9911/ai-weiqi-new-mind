# ai-weiqi-new-mind

围棋定式 / 套路 / 避雷的"AI + 老师讲解"学习库。把围棋老师的视频讲解整理成 **SGF 变化树**,每一手配上:

- **老师讲解**(视频语音转写,按时间点可跳回视频)
- **要点与考量**(从口述里提炼的取舍理由、周边条件、避雷)
- **AI 局部评估**(KataGo 只在该定式涉及的区域内搜索,给出每个候选点比局部最优差几目;老师走的每一手都会单独评估)
- **周边子力影响**(去掉区域外子力后结论是否变化)

解决的痛点:KataGo 只会看全局胜率,不方便"只研究局部定式,又能看周边子力/征子怎么影响选择"。

## 使用
双击 `index.html`(离线,数据在 `data/library.js`)。若浏览器对 `file://` 限制,可运行 `python pipeline/serve.py`(无缓存本地服务,端口 8765)。
方向键 ←→ 步进、↑↓ 选变化;棋盘上 **半透明棋子=AI候选**(颜色=行棋方)、**圈色/数字=比局部最优差几目**、**蓝色虚线圈+序号=老师在视频里走的变化**;悬停候选看 AI 变化,点击固定;页面左上角显示"界面版本 / 数据时间"。

## 目录
```
index.html            单文件查看器
data/sgf/…            生成的 SGF(标准 SGF,Lizzie/KataGo GUI/Sabaki 可打开;PL/AN 为本项目扩展属性)
data/sources/…        视频清单与合并计划(plan.json 决定哪些视频合成一个 SGF)
data/library.js       打包文件(tools/build.ps1 生成)
tools/                build.ps1 打包;fetch_playlists.ps1 抓列表;sync_pipeline.ps1 同步流水线脚本
pipeline/             无人值守流水线:下载→转写→识谱→变化树→KataGo→SGF
engine-config/        KataGo 配置(不含二进制与权重)
docs/usage.md         命名规则、SGF 约定、如何新增 UP 主
remote/               (开发中)远程 GPU 方案
```

## 流水线(`pipeline/`)
`orch2.py` 全自动:yt-dlp 下载 → `tr.py`(faster-whisper) → `board.py`(OpenCV 识谱) → 变化树 → `analyze2.py`(KataGo 分析) → 合成 SGF。`regen.py` 用缓存重生成 SGF(改错字词典后用,`NOAN=1` 跳过分析)。脚本里路径是硬编码的 Windows 路径(`D:\tmp\work` 等),换机器需修改。
要点摘要 `kp_*.json`(节点号→要点)由大模型根据口述提炼。

### 关键正确性约定(踩过的坑,见 CHANGELOG)
- KataGo 配置 `reportAnalysisWinratesAs=BLACK`,所有分数是黑方视角,**必须转换成行棋方视角**再排序。
- 只搜局部区域时不展示全盘胜率,只展示"比局部最优差几目"。
- 行棋方由 SGF `PL[]` 属性给出;变化预览的棋子颜色从行棋方起交替。
- 老师走的着法不一定在 KataGo 前几选里,必须单独评估并在棋盘上标出。
