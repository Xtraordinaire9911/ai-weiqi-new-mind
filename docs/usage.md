# 定式库 (josekiapp) / Joseki library (josekiapp)

双击 `index.html` 即可离线使用，无需服务器、Node 或 Python。方向键：←→ 步进，↑↓ 选变化，另外还有 Home/End。点击评论里的 `@mm:ss`，会跳到视频的对应时间。

Double-click `index.html` to use it offline, with no server, Node or Python needed. Keys: ←→ step, ↑↓ choose a variation, Home/End. Clicking an `@mm:ss` in a comment jumps to that time in the video.

## 命名规则 (SGF) / Naming rules (SGF)

文件名格式为 `<角>-<挂法/手法>-<夹击或应对>.sgf`，三部分依次是角上的布局（星位、小目）、挂法或手法（小飞挂）、夹击或应对（一间低夹）。例如 `星位-小飞挂-一间低夹`、`小目-小飞挂-二间高夹`。同一个“开局加夹法”下的所有细分分支放在同一个 SGF 里，用变化树表示；夹法不同则分开存成不同文件。

A file is named `<角>-<挂法/手法>-<夹击或应对>.sgf`. The three parts are the corner opening (星位, 小目), the approach or technique (小飞挂) and the pincer or response (一间低夹). Examples are `星位-小飞挂-一间低夹` and `小目-小飞挂-二间高夹`. All sub-branches of the same opening plus pincer go into one SGF as a variation tree, and a different pincer gets its own file.

目录为 `data/sgf/<来源>/<系列>/`，例如 `data/sgf/chenlintao/定式大全/`。避雷和套路研究两个系列暂时按一个视频一个文件存放（`避雷-NN-标题`、`套路研究-NN-标题`，NN 是视频序号，最后一段是视频标题）。内容填充好之后，可以按上面的规则合并并改名，改的是 `plan.json`。

The folder is `data/sgf/<来源>/<系列>/`, for example `data/sgf/chenlintao/定式大全/`. The 避雷 and 套路研究 series currently keep one file per video (`避雷-NN-标题`, `套路研究-NN-标题`, where NN is the video number and the last part is the video title). Once their content is filled in, they can be merged and renamed by the rule above, by editing `plan.json`.

## 数据格式 / Data format

纯 SGF（FF4，UTF-8）。口述的解析写在各节点的 `C[]` 里，标记用标准的 TR/SQ/CR/LB 属性，因此与 Lizzie、KataGo GUI、Sabaki 互通。

Plain SGF (FF4, UTF-8). The parsed explanation goes into the `C[]` of each node, and marks use the standard TR/SQ/CR/LB properties, so the files work with Lizzie, KataGo GUI and Sabaki.

## 新增 UP 主或系列（无需改代码） / Adding an uploader or a series (no code changes)

1. `data/sources/<id>/index.json`：视频列表，每一项形如 `{season,seasonName,idx,bvid,title}`。陈林涛的这份由 `tools/fetch_playlists.ps1` 生成。

   `data/sources/<id>/index.json`: the video list, with entries like `{season,seasonName,idx,bvid,title}`. For 陈林涛 (Chen Lintao) it is generated by `tools/fetch_playlists.ps1`.

2. `data/sources/<id>/plan.json`：参照 chenlintao 的那份来写，其中 `series` 是系列名，`merge` 指定哪些视频合并成一个 SGF。

   `data/sources/<id>/plan.json`: follow the one for chenlintao, which has `series` (the series names) and `merge` (which videos are merged into one SGF).

3. 运行 `powershell -ExecutionPolicy Bypass -File tools/build.ps1`。它会生成缺失的 SGF 骨架（不会覆盖已经填好的内容），并打包出 `data/library.js`。

   Run `powershell -ExecutionPolicy Bypass -File tools/build.ps1`. It generates the missing SGF skeletons, never overwriting content that is already filled in, and bundles `data/library.js`.

4. 用 Lizzie 或 KataGo GUI 打开 SGF，摆出变化图并写好解析，保存后再运行一次 build。

   Open the SGF in Lizzie or KataGo GUI, lay out the variations and write the explanation, save, then run the build again.
